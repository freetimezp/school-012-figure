01 — THE BASICS

More than
just an image.

HTML gives us dedicated elements to group visual content with its description. Let's understand how they work together.

01

figure

The figure element represents self-contained content, such as an image, illustration, diagram or code example.

<figure>
02

figcaption

The figcaption element provides a caption or description for its parent figure.

<figcaption>
03

img

The image element displays visual content. Its alt attribute provides alternative text for meaningful images.

<img>
HTML / 001

Build your first figure.

HTML5 
<figure>
    <img
        src="mountain.jpg"
        alt="Mountain landscape reflected in a lake"
    >

    <figcaption>
        A peaceful morning in the mountains.
    </figcaption>
</figure>
✳

The figure element groups the image and its caption into one meaningful unit.

02 — VISUAL EXAMPLES

03 — UNDERSTAND THE DIFFERENCE

Caption vs alt text.

They both describe images, but they serve different purposes.

ALTERNATIVE TEXT

alt attribute

Describes the image when it cannot be seen. It is especially important for screen-reader users.

EXAMPLE alt="A red bicycle beside a brick wall"
VISIBLE DESCRIPTION

figcaption

Adds visible context, explanation, credit or information related to the image.

EXAMPLE A vintage bicycle photographed in Copenhagen.
✳

A caption does not replace meaningful alt text. They can complement each other.
